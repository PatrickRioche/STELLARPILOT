# Sécurité

La surface de sécurité future inclura notamment :
- accès réseau au serveur de contrôle ;
- commandes de mouvement de monture ;
- mise à jour du logiciel ;
- stockage éventuel des profils matériels ;
- accès depuis Android ;
- exposition éventuelle hors du réseau local.

Aucun mécanisme de sécurité n'est considéré comme défini avant les ADR associés.
Les POC réseau doivent rester, par défaut, sur un environnement local de test.
