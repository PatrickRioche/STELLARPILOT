# Spécification — trajectoire "smart telescope"

## Expérience cible à terme

1. Détecter le matériel.
2. Initialiser la session.
3. Faire l'autofocus.
4. Capturer une image.
5. Résoudre le champ par astrométrie.
6. Déterminer la position dans le ciel.
7. Corriger/centrer la monture.
8. Suivre la cible.
9. Empiler les images.
10. Identifier et présenter les objets observés.

Cette chaîne constitue la vision fonctionnelle, pas le périmètre du premier MVP.
