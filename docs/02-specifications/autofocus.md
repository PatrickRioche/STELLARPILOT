# Spécification — autofocus

## But
Obtenir automatiquement une position de mise au point reproductible à partir
d'images provenant de caméras hétérogènes et d'un focuser piloté via INDI.

## Points à spécifier
- métrique de netteté ;
- sélection d'étoiles ;
- séquence de positions ;
- gestion du backlash ;
- temps d'exposition ;
- critères de convergence ;
- conditions d'échec ;
- restauration de la position ;
- journal de mesure.

## Sortie attendue de la Phase 0
Une stratégie algorithmique candidate et un POC reproductible.
