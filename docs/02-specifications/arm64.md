# Spécification — Linux ARM64

Le serveur ARM64 doit pouvoir :
- communiquer avec INDI ;
- exécuter les traitements astronomiques retenus ;
- exposer une API locale ;
- journaliser les opérations ;
- fonctionner de manière autonome après démarrage ;
- être empaqueté de façon reproductible.

Le mode d'intégration exact à Astroberry doit être validé par faisabilité.
