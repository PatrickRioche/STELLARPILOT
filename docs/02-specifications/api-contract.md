# Spécification — API serveur

À définir avant implémentation :
- transport ;
- découverte ;
- version de protocole ;
- authentification éventuelle ;
- commandes synchrones/asynchrones ;
- événements ;
- progression des tâches ;
- annulation ;
- erreurs ;
- compatibilité ascendante.

Principe : l'API ne doit pas exposer directement les détails d'un pilote
constructeur.
