# Spécification — astrométrie

## But
Déterminer où pointe le système à partir d'une image.

## Fonctions envisagées
- plate solving ;
- extraction RA/DEC et orientation ;
- calcul d'erreur de pointage ;
- synchronisation monture ;
- boucle de recentrage ;
- identification des objets du champ.

## Points de faisabilité
- solveur local ;
- index nécessaires ;
- performances ARM64 ;
- résolution sans connexion Internet ;
- formats d'images ;
- tolérance aux champs difficiles.
