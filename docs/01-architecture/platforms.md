# Plateformes

## Linux ARM64
Cible embarquée principale pour le serveur StellarPilot.

À vérifier :
- distribution(s) réellement supportée(s) ;
- disponibilité INDI ;
- disponibilité du solveur astrométrique retenu ;
- ressources CPU/RAM ;
- accès USB ;
- installation et mise à jour.

## Android
Cible de contrôle utilisateur.

À vérifier :
- niveau Android minimal ;
- protocole réseau ;
- découverte du serveur ;
- fonctionnement hors Internet ;
- distribution APK ;
- gestion des permissions.
