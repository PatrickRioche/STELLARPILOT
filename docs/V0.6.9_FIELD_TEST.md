# StellarPilot V0.6.9 — checklist terrain

## Objectif

Valider la nouvelle initialisation HOME OnStep, la chaîne Dark/Stacking et la conservation des RAW après les anomalies observées le 15/09/2026.

## 1. Connexion

- Monture OnStep connectée via INDI.
- Caméra connectée.
- GPS avec fix si possible.
- TIME_UTC OnStep synchronisé et vérifié par StellarPilot.

## 2. HOME mécanique et astrométrie

1. Placer physiquement la monture en HOME/CWD : contrepoids vers le bas, tube parallèle à l'axe polaire.
2. Orienter vers le pôle céleste. Polaris doit seulement être dans le champ ; elle n'a pas besoin d'être centrée.
3. Lancer la première capture/astrométrie de 4 s.
4. StellarPilot refuse le Reset HOME si |DEC| < 80°.
5. Confirmer explicitement la position HOME mécanique.
6. StellarPilot :
   - vérifie TIME_UTC ;
   - synchronise la position OnStep depuis le GPS ;
   - refuse une monture parkée ;
   - coupe le suivi si nécessaire ;
   - envoie `TELESCOPE_HOME.SET` via INDI (OnStep `:hF#`).
7. Lancer `GOTO ZONE HAUTE • ASTROMÉTRIE • SYNC`.
8. La seconde cible doit être haute mais hors zone polaire ; le SYNC est refusé au-delà de |DEC| > 80°.
9. Vérifier qu'une nouvelle astrométrie indique une erreur de pointage très inférieure aux ~5–6° observés le 15/09.

## 3. Darks

- Nombre par défaut : **10**.
- Exposition par défaut : 4,0 s.
- Réglage avant acquisition : pas de ±0,5 s.
- La même préférence d'exposition est reprise par l'écran Capture.
- Compatibilité Master Dark : caméra, exposition, gain, offset, binning, dimensions, Bayer et température.
- Tolérance thermique runtime : **±5 °C**.
- En cas de rejet, StellarPilot doit afficher le critère fautif et proposer de refaire les darks.

## 4. Stacking

Chaîne attendue :

`RAW FITS → sélection Master Dark → calibration → qualité → registration → live stack → astrométrie périodique`

- L'astrométrie n'est pas faite sur chaque pose.
- Contrôle périodique : toutes les 8 images acceptées, ou plus tôt en cas de dérive de registration.
- Une astrométrie non résolue ne supprime pas le RAW et ne doit pas arrêter le stacking à elle seule.
- Une solution astrométrique valide révélant un décentrage peut mettre le stacking en pause pour recentrage.

## 5. Arrêt et Galerie

Après arrêt du stacking et avec au moins une image acceptée, utiliser :

**ARRÊT FINAL • ENREGISTRER DANS GALERIES**

La galerie doit contenir :

- `final.fits`
- `final.jpg`
- `thumbnail.jpg`
- `session.json`
- `siril_manifest.json`
- `lights/accepted/*.fits`
- `lights/rejected/*.fits`
- `calibration/master_dark.fits` si utilisé
- `calibration/hot_pixels.fits` si disponible

Les RAW acceptés et rejetés sont conservés afin de permettre un retraitement ultérieur dans Siril.

## 6. Points à relever pendant la soirée

Pour chaque cible test :

- cible demandée RA/DEC ;
- position OnStep annoncée ;
- solution astrométrique réelle ;
- erreur angulaire ;
- côté de pilier ;
- température du LIGHT et du Master Dark ;
- nombre de poses capturées / acceptées / rejetées ;
- raison de chaque rejet ;
- résultat du contrôle astrométrique périodique.
