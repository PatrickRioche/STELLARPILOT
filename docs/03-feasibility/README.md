# Dossier de faisabilité

Chaque hypothèse critique reçoit :
1. une question ;
2. un protocole de test ;
3. un environnement ;
4. une preuve reproductible ;
5. un résultat ;
6. des limites ;
7. une décision Go / Go avec réserve / No-Go.

Une impression subjective ou un simple "cela devrait fonctionner" ne constitue
pas une preuve de faisabilité.
