# Nommage des artefacts

Format prévu :

```text
StellarPilot-vX.Y.Z-linux-arm64.tar.gz
StellarPilot-vX.Y.Z-android.apk
StellarPilot-vX.Y.Z-source.zip
StellarPilot-vX.Y.Z-SHA256SUMS.txt
```

Optionnel à terme :
```text
StellarPilot-vX.Y.Z-linux-arm64.deb
```

Les variantes de debug, POC ou CI ne doivent pas être présentées comme des
releases publiques stables.
