# StellarPilot v0.1.0-poc

Date : 17 août 2026.

## Objet

Premier jalon publiable du POC réunissant `stellarpilot-server` et `StellarPilot-app`.

## Validé

- serveur FastAPI exécutable sur Raspberry Pi 5 ;
- API REST de statut accessible sur le LAN ;
- WebSocket fonctionnel ;
- application Android Kotlin/Compose ;
- variante Android de simulation ;
- variante Android pour appareil réel ;
- build APK via GitHub Actions ;
- test réel tablette Android -> Raspberry Pi 5 ;
- HTTP 200 sur `/status` depuis l’APK ;
- WebSocket accepté par le serveur ;
- documentation d’exploitation et de test.

## Artifacts attendus

- `StellarPilot-device-debug.apk` ;
- `StellarPilot-simulation-debug.apk` ;
- `stellarpilot-server-v0.1.0-poc.tar.gz` ;
- `openapi.json`.

## Statut du POC

Cette version valide la couche réseau et DevOps Android ↔ serveur.

Elle ne valide pas encore le Gate POC complet, qui nécessite la chaîne :

```text
Android
  -> Raspberry Pi
  -> INDI réel
  -> monture/caméra
  -> capture réelle
  -> plate solving local réel
  -> résultat astrométrique vers Android
```

## Prochaine étape

Exposer les équipements INDI réels dans `stellarpilot-server` et afficher leur état dans l’APK.
