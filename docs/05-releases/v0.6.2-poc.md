# StellarPilot v0.6.2-poc

Date : 2026-09-07

## Objectif

Corriger la composition du catalogue céleste embarqué afin que les étoiles brillantes portant un nom usuel soient accessibles depuis l'écran Ciel et la recherche générale, sans dépendre d'Internet.

## Catalogue céleste

- ajout d'une source interne `StellarPilot Bright Stars 2026.09` ;
- intégration des étoiles brillantes déjà utilisées par l'assistant d'alignement dans `catalog.sqlite3` ;
- ajout de Polaris, avec les alias `Étoile polaire` et `Polaris A` ;
- recherche possible par nom usuel, alias français ou identifiant Bayer ;
- exemples couverts : Vega / Véga, Arcturus, Sirius, Deneb, Altair, Polaris / Étoile polaire ;
- conservation des coordonnées J2000 et de la magnitude visuelle ;
- type catalogue : `star` / `Étoile`.

## Migration de la base existante

Le fichier `server/data/catalog.sqlite3` reste une donnée persistante et n'est pas remplacé lors du déploiement sur le Raspberry Pi.

La v0.6.2 ajoute donc une migration idempotente côté serveur : au démarrage, les étoiles brillantes manquantes sont ajoutées à la base existante. Les déploiements suivants ne créent pas de doublons.

## Alignement

La définition des étoiles brillantes est centralisée dans `app/catalog/bright_stars.py`. Le module historique `app/sky/catalog.py` devient un alias de compatibilité vers cette source unique.
