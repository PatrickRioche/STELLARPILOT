# StellarPilot v0.6.8-poc

## Calibration équatoriale zénithale sûre

Cette version corrige le workflow de première astrométrie utilisé avec une monture équatoriale allemande démarrant près du pôle céleste.

### Problème traité

Un plate solving effectué près de Polaris peut fournir un centre astrométrique parfaitement valide alors que la monture est encore très proche de DEC +90°. Dans cette zone, l'ascension droite est mal conditionnée : des valeurs de RA très différentes peuvent représenter des directions physiquement très proches. La v0.6.7 pouvait synchroniser OnStep immédiatement sur cette première solution, sans mouvement physique de la monture.

### Nouveau workflow

1. Démarrage / HOME près de Polaris.
2. Première capture et résolution astrométrique.
3. Aucun SYNC OnStep n'est effectué à ce stade.
4. Un second déclenchement de l'action de première astrométrie lance la calibration zénithale :
   - calcul d'une zone haute sûre à partir de la position et de l'heure de session ;
   - cible volontairement décalée du méridien (HA = -1,5 h, soit 22,5° à l'est) ;
   - déclinaison proche de la latitude mais limitée à ±65° ;
   - altitude cible minimale de 55° ;
   - GOTO J2000 vers cette zone ;
   - attente du retour Tracking/Idle ;
   - stabilisation ;
   - nouvelle capture ;
   - contrôle qualité ;
   - nouvelle résolution astrométrique ;
   - SYNC OnStep uniquement sur cette seconde solution.
5. La préparation ne peut continuer que lorsque le SYNC zénithal est validé.

### Garde-fou serveur

`sync_mount_j2000()` refuse désormais tout SYNC pour `|DEC| > 80°`, indépendamment du client qui émet la requête.

### Calcul hors ligne

La cible de calibration utilise le calcul sidéral local déterministe de StellarPilot. Aucune donnée IERS réseau n'est nécessaire sur le Raspberry Pi. Astropy n'est utilisé que pour la précession FK5 entre l'époque de date et J2000.

### API ajoutée

`GET /mount/calibration-target`

La réponse fournit notamment :

- RA/DEC J2000 de la cible ;
- RA/DEC époque de date ;
- altitude et azimut ;
- angle horaire ;
- source de position ;
- source horaire.
