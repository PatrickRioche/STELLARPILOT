# StellarPilot v0.7.0-beta

Date : 8 septembre 2026

## Objet

`v0.7.0-beta` est la première beta intégrée de StellarPilot. Elle fige une base cohérente après validation sur matériel réel de la chaîne Android -> Raspberry Pi -> INDI -> caméra / monture OnStep.

Cette version remplace les jalons `0.6.x-poc` utilisés pendant les essais de préparation et marque le passage d'un POC de faisabilité à une beta destinée aux validations terrain répétables.

## Monture / OnStep

- connexion réelle à `LX200 OnStep` via INDI ;
- liaison série USB confirmée ;
- GOTO réel validé ;
- suivi sidéral associé au GOTO ;
- transformation J2000 -> époque du jour lorsque OnStep expose `EQUATORIAL_EOD_COORD` ;
- trajectoire logique Arcturus -> Vega observée seconde par seconde avec `_STATE=Busy`, puis arrivée `_STATE=Ok` ;
- coordonnées finales conformes à la cible ;
- mouvement physique rapide et cohérent de la monture confirmé lors des essais suivants ;
- lecture des propriétés INDI critiques par noms exacts afin d'éviter les blocages de `indi_getprop` avec les wildcards.

## Temps de session

- synchronisation `TIME_UTC` explicite depuis GPS/Android une fois par session ;
- écriture suivie d'un readback OnStep ;
- vérification de session conservée jusqu'à 12 h si le point de consigne et l'offset restent identiques ;
- prise en compte du comportement du driver OnStep : `TIME_UTC` est un point de consigne statique et ne doit pas être utilisé comme horloge temps réel ;
- les GOTO ne réécrivent plus l'horloge de la monture avant chaque mouvement.

## Caméra et astrométrie

Les acquis des releases précédentes sont conservés :

- caméra Player One Uranus-C réelle via INDI ;
- FITS RAW16 3856 × 2180 ;
- matrice Bayer RGGB ;
- aperçu JPEG couleur ;
- plate solving local via astrometry.net / `solve-field` ;
- conservation du FITS brut pour l'astrométrie ;
- référentiel optique empirique d'environ 1,2183 arcsec/pixel pour un champ d'environ 1,305° × 0,738°.

## Android

- application native Kotlin + Jetpack Compose ;
- workflow de préparation : `Connexion -> Moteurs -> Astrométrie -> Étoile -> Bahtinov -> Prêt` ;
- version produit commune `0.7.0-beta` pour les variantes `device` et `simulation` ;
- distinction du backend par `BACKEND_MODE`, sans suffixe de version ;
- `versionCode = 70` pour permettre une mise à jour propre au-dessus des builds `0.6.x` déjà installés.

## DevOps

- GitHub est l'unique source de vérité ;
- aucun workflow Git n'est utilisé sur le Raspberry Pi ;
- le Pi reste une cible d'exécution et de déploiement ;
- le workflow de release vérifie désormais que le tag correspond exactement au fichier `VERSION` ;
- les notes de release sont sélectionnées automatiquement à partir du tag ;
- les APK, l'archive serveur et OpenAPI portent le numéro de release ;
- un fichier `SHA256SUMS` est généré pour les artefacts publiés.

## Validation du 8 septembre 2026

Les essais ont confirmé :

- monture OnStep connectée et pilotable ;
- synchronisation horaire de session fonctionnelle ;
- transformation correcte des coordonnées Vega et Arcturus ;
- progression complète du GOTO côté INDI ;
- mouvement mécanique rapide et cohérent de la monture ;
- absence de besoin de resynchroniser l'horloge avant chaque GOTO.

Les nuages arrivés en fin de séance ont empêché la validation optique finale sur une étoile après les derniers correctifs.

## Limites connues

- validation Bahtinov complète à poursuivre sous ciel dégagé ;
- centrage automatique et contrôle plate solving après GOTO à valider complètement sur ciel réel ;
- les essais optiques finaux de cette beta restent à compléter dès la prochaine fenêtre météo ;
- l'identifiant OpenAPI peut rester temporairement compatible avec le jalon API 0.6 pendant cette beta ; la version produit officielle est celle du fichier `VERSION` et du tag GitHub.

## Statut

`v0.7.0-beta` est une pré-release technique intégrée. Elle constitue la nouvelle base de référence pour les prochains essais terrain mais ne signifie pas encore que le Gate G0 est franchi.
