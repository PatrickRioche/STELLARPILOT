# StellarPilot v0.5.0-poc

Date : 24 août 2026

## Objet

Cette pré-release fige un jalon majeur du POC StellarPilot avec une chaîne fonctionnelle Android, Raspberry Pi, INDI, caméra réelle et astrometry.net.

## Android

- connexion serveur renforcée et récupération après erreur ;
- serveur device : http://10.42.0.1:8000/ ;
- serveur simulation : http://10.42.0.1:8008/ ;
- réglage de l'exposition de 1 ms à 10 s ;
- exposition initiale de 1 ms pour les essais de jour ;
- affichage des résultats d'astrométrie : RA, DEC, orientation et échelle ;
- client préparé pour recevoir le nombre et les positions des étoiles détectées ;
- correction des problèmes d'encodage de l'interface ;
- sorties Gradle déplacées hors de Google Drive dans %LOCALAPPDATA%\StellarPilot\android-build.

## Serveur

- capture réelle via INDI ;
- caméra Player One Uranus-C validée ;
- FITS RAW16 3856 x 2180 ;
- matrice Bayer RGGB ;
- astrométrie réelle via astrometry.net solve-field ;
- conservation du FITS brut pour l'astrométrie ;
- génération d'un aperçu JPEG couleur via /camera/preview.jpg ;
- débayer RGGB et étirement global RGB préservant les relations entre canaux.

## Validation

- build Android deviceDebug : SUCCESSFUL ;
- installation APK par ADB : réussie ;
- capture réelle : réussie ;
- aperçu JPEG : HTTP 200 ;
- BAYERPAT : RGGB ;
- canaux RGB distincts ;
- service stellarpilot-server opérationnel sur Raspberry Pi.

## Limites connues

- le plate solving doit encore être validé de nuit sur un vrai champ stellaire ;
- un timeout astrométrique de jour sans étoiles est attendu ;
- le serveur ne retourne pas encore les positions individuelles des étoiles ;
- la balance des blancs de l'aperçu couleur reste à améliorer ;
- le serveur de simulation sur le port 8008 reste à implémenter.

## Statut

v0.5.0-poc est une pré-release technique et ne constitue pas encore le franchissement du Gate G0.
