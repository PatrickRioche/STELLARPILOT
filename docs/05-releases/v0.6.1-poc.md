# StellarPilot v0.6.1-poc

Date : 2026-09-06

## Objet de la livraison

Consolider le setup terrain repris après les essais du 5 au 6 septembre 2026, avec OnStepX 10.28u et une position monture de nouveau cohérente dans INDI et StellarPilot.

## Changements

- nouveau diagnostic serveur `GET /mount/firmware` ;
- lecture réelle de `LX200 OnStep.Firmware Info.Number` ;
- affichage Android du firmware OnStepX, sans valeur codée en dur ;
- conservation de la télémétrie réelle `EQUATORIAL_EOD_COORD` ;
- correction de la détection de paire App / Serveur : comparaison des SHA Git au lieu des timestamps de build ;
- serveur `0.6.1-poc` ;
- Android `0.6.1`, versionCode 7.

## Référence terrain

Lors de la préparation de cette livraison :

- firmware OnStep publié par INDI : `10.28u` ;
- monture : `LX200 OnStep` ;
- état `/mount/status` : `idle` ;
- propriété de coordonnées : `EQUATORIAL_EOD_COORD` ;
- état INDI : `Ok` ;
- position virtuelle : `false`.

La logique RA/DEC n'est donc pas modifiée par cette livraison.

## Déploiement

Le Raspberry Pi ne contient pas de dépôt Git. Le serveur doit être livré depuis le PC avec :

```powershell
.\tools\deploy-server.ps1
```

Le script conserve `.venv/` et `data/` sur le Raspberry Pi.

## Contrôles après déploiement

```powershell
Invoke-RestMethod "http://192.168.1.46:8000/build" | ConvertTo-Json -Depth 6
Invoke-RestMethod "http://192.168.1.46:8000/mount/firmware" | ConvertTo-Json -Depth 6
Invoke-RestMethod "http://192.168.1.46:8000/mount/status" | ConvertTo-Json -Depth 6
```

Résultat attendu pour le firmware de référence : `number = 10.28u`.
