# StellarPilot v0.7.1-beta

Date : 9 septembre 2026

## Objet

`v0.7.1-beta` est une release corrective de cohérence de version et de déploiement. Elle ne change pas le comportement fonctionnel validé dans `v0.7.0-beta`.

## Corrections

- API FastAPI alignée sur `0.7.1-beta` au lieu de l’ancienne valeur résiduelle `0.6.0-poc` ;
- Android aligné sur `0.7.1-beta` avec `versionCode = 71` ;
- script `tools/deploy-server.ps1` rendu indépendant d’une version codée en dur ;
- le script lit désormais la version attendue depuis le fichier racine `VERSION` ;
- contrôle post-déploiement de la version OpenAPI et des routes principales de monture, GOTO et synchronisation horaire.

## Héritage de v0.7.0-beta

Tous les acquis de `v0.7.0-beta` sont conservés :

- chaîne Android -> Raspberry Pi -> INDI -> OnStep/caméra ;
- GOTO réel OnStep et suivi sidéral ;
- conversion J2000 -> époque du jour ;
- synchronisation `TIME_UTC` une fois par session avec readback ;
- capture Player One Uranus-C ;
- astrométrie locale via astrometry.net ;
- workflow de préparation et Bahtinov.

## Limites connues

- validation Bahtinov complète à terminer sous ciel dégagé ;
- validation finale du centrage après GOTO à poursuivre sous ciel réel ;
- `0.7.1-beta` reste une pré-release.
