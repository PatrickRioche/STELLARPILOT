# Glossaire

- **INDI** : couche de pilotage de périphériques astronomiques.
- **Mount** : monture astronomique AZ ou EQ.
- **Focuser** : moteur de mise au point.
- **Plate solving** : détermination astrométrique du champ d'une image.
- **ARM64** : architecture cible pour le serveur embarqué.
- **APK** : paquet d'application Android.
- **POC** : preuve de concept.
- **ADR** : Architecture Decision Record.
- **Gate** : point de décision Go/No-Go.
