# Vision

StellarPilot doit permettre de composer un télescope intelligent à partir de
matériels hétérogènes compatibles INDI, sans imposer une marque unique.

La valeur du projet repose sur :
- l'interopérabilité ;
- l'automatisation ;
- l'expérience utilisateur simplifiée ;
- la transparence du logiciel libre ;
- la possibilité d'utiliser du matériel existant.
