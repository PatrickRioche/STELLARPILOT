# Menaces à étudier avant exposition réseau

- commande non autorisée d'une monture ;
- service accessible hors LAN par erreur ;
- client Android non authentifié ;
- injection via paramètres externes ;
- dépendances compromises ;
- mise à jour falsifiée ;
- fuite de journaux ou d'informations réseau ;
- déni de service pendant une session.

La Phase 0 doit décider quel niveau d'authentification est requis sur un LAN.
